Understand how the CPU chooses its next process

CPU scheduling is the operating system's way of deciding which ready process gets to use the processor next. Scheduling algorithms help share CPU time efficiently and predictably when several processes compete to run.

Use this simulator to compare four classic algorithms, follow their execution on a timeline, and see how each scheduling decision affects waiting, turnaround, and response times.

Scheduling strategies

Algorithms

01 / Arrival order

FCFS

First Come, First Served runs ready processes in the order they arrive.

Key characteristic Simple and non-preemptive; a long job can make others wait.

02 / Shortest job

SJF

Shortest Job First selects the available process with the smallest burst time.

Key characteristic Non-preemptive; can reduce average waiting when short jobs are available.

03 / Priority value

Priority Scheduling

Runs the ready process with the best priority; in this simulator, a lower value means higher priority.

Key characteristic Non-preemptive; equal priorities are resolved by arrival, then entry order.

04 / Time slices

Round Robin

Shares CPU time in turns, giving each ready process up to one time quantum.

Key characteristic Preemptive and cyclic; the quantum controls the length of each turn.
